# RVC变声（dsh-rvc）

DeepSeek Harness（DSH）插件，一个中间工具，做两件事：

- **变声**：输入本机上的一个音频或视频文件，转成标准 WAV，交给容语（RongYu，RVC 变声）变成容语里当前模型的声音，输出新生成的 WAV 文件路径。
- **人声分离**：输入本机上的一首歌，交给容语轻量版分成人声和伴奏两个 WAV 文件，输出两个文件的路径。

插件只生成文件，不收发任何消息。文件从哪里来、生成后交给谁，由调用它的一方决定。

## 工作方式

插件提供两个工具（给大肥鱼用）和一个服务 `rvc`（给其它插件用）：

| 工具 | 做什么 |
|---|---|
| `rvc_convert` | 变声：给出一个本机音频或视频文件，返回变声后的 WAV 文件路径 |
| `rvc_separate` | 人声分离：给出一个本机音频或视频文件，返回人声、伴奏两个 WAV 文件的路径 |

## 怎么让大肥鱼做人声分离

跟大肥鱼说：

- 「把 D:\音乐\晴天.mp3 的人声和伴奏分开」
- 「提取 D:\音乐\晴天.mp3 的人声」
- 「把 D:\音乐\晴天.mp3 的伴奏去掉」，或者「只要 D:\音乐\晴天.mp3 的伴奏」

它会调用 `rvc_separate`，把人声和伴奏分别存成 WAV 文件，并告诉你两个文件在哪。不管你要的是人声还是伴奏，两个文件都会生成。

- 默认用「去伴奏（激进）」。说「用去伴奏分离」可以换成温和一些的方式；说「用提主旋律分离」只留主唱，和声会分到伴奏里。
- 也可以说对话里已经有的文件，比如「把刚才那个文件的人声分离出来」。
- 分离完可以接着说「把人声变声」，大肥鱼会把人声文件交给 `rvc_convert`。
- 一次处理一个文件。说「把这三首都分离一下」时，大肥鱼会一首一首地处理。

## 环境要求

- Windows 10/11 x64
- DeepSeek Harness 0.2.1-rc.3 或更新版本
- 变声：容语（RongYu）开着，并且在「设置 → 语音接口」里打开了接口。没接容语时，`rvc_convert` 只转格式，不变声。
- 人声分离：
  - 容语轻量版开着，并且是支持人声分离的新版本。容语完整版暂时不支持。
  - 容语里选的是 2026 版 RVC 整合包。分离用的是整合包里自带的分离模型，2024 版整合包没有。
  - 和变声一样，需要在容语里打开语音接口，并在插件里填好连接串。

## 安装

插件没有发布到 npm 和插件市场，用本机文件夹安装：

1. 把插件文件夹放在一个固定位置，比如 `D:\DSH-plugins\dsh-rvc`。DSH 直接使用这个文件夹，装好后不要移动或删除它。文件夹里要带着 `node_modules`（插件依赖 silk-wasm）；没有的话，在插件文件夹里执行一次 `npm install --omit=dev --registry=https://registry.npmmirror.com`。
2. 在 DSH 的插件页点「添加插件」，在「包名或地址」里填插件文件夹的完整路径，安装。
3. 完全退出 DSH（托盘图标右键退出），再重新打开。设置里会多出「RVC变声」页。

更新插件时，替换文件夹里的文件，再完全退出并重新打开 DSH。

## 设置

在 DSH 设置的「RVC变声」页里：

- **容语变声（RVC）**：在容语「设置 → 语音接口」点「复制」，把连接串粘贴过来，点「保存并测试」。连接串只能指向本机（127.0.0.1）。开关打开时，传进来的音频都会交给容语变声；关掉时只转格式。「重新检查」会重新测试和容语的连接。
- **人声分离**：默认打开。打开时大肥鱼能用 `rvc_separate`；关掉后大肥鱼看不到这个工具，其它插件也调用不了分离。卡片里会显示当前连接的容语支不支持人声分离。
- **保留生成的文件**：默认生成的 WAV 过 10 分钟自动删除，可以改成 1 到 1440 分钟。打开开关后会一直保存在你指定的文件夹里（不填就存到插件自己的 `kept` 文件夹），需要自己清理。变声和人声分离生成的文件都按这个设置处理。

变声用的是容语里当前选中的模型和设置。想换声音或者调音调，在容语里改。

## 大肥鱼能用的工具

| 工具 | 参数 | 说明 |
|---|---|---|
| `rvc_convert` | `file`：本机音频或视频文件的完整路径 | 转成标准 WAV，开着容语变声时会变声。只生成文件。一直可用 |
| `rvc_separate` | `file`：本机音频或视频文件的完整路径；`mode`：处理方式，可以不填 | 分成人声和伴奏两个 WAV 文件。`mode` 可以是「去伴奏（激进）」（默认）、「去伴奏」、「提主旋律」。打开「人声分离」时才有 |

返回值：

- `rvc_convert`：成功时是 `{ ok, path, seconds, sampleRate, expiresInMinutes }`
- `rvc_separate`：成功时是 `{ ok, vocal, instrumental, seconds, mode, expiresInMinutes }`，`vocal` 是人声文件，`instrumental` 是伴奏文件
- 失败时都是 `{ ok: false, message }`

生成的文件会过期删除，调用方要在过期前用完。

## 给其它插件用

RVC变声提供一个名为 `rvc` 的服务：

```js
const rvc = ctx.get('rvc')
const a = await rvc.convert({ path: 'D:\\语音\\a.silk' })
const b = await rvc.toWav({ buffer })
const c = await rvc.separate({ path: 'D:\\音乐\\晴天.mp3' }, { mode: '去伴奏（激进）' })
await rvc.release(a.id)
```

- `convert({ path } 或 { buffer }, { rvc })`：`rvc: false` 表示这次不变声，不传就按设置。
- `toWav(input)`：只转格式。
- `separate({ path }, { mode })`：人声分离。返回 `{ ok, mode, seconds, vocal, instrumental, kept, expiresAt }`，`vocal` 和 `instrumental` 里各有 `id` 和 `path`。关掉「人声分离」时会报错。
- `status()`：容语的连接状态、排队数，以及支不支持人声分离。
- `release(idOrPath)`：马上删除生成的临时文件，保留模式下不删。
- `version`：插件版本号。

`convert` 的返回值里有 `id`、`path`、`seconds`、`sampleRate`、`kept`、`expiresAt`、`steps`、`model`。

## 支持的格式

变声输出的标准 WAV：单声道、16 位 PCM，采样率保持原样，最高 48 kHz。

人声分离输出的 WAV：44.1 kHz 立体声、32 位浮点。一首 4 分钟的歌，每个文件大约 85 MB。

能读的格式：QQ/微信语音（SILK、AMR）、MP3、M4A/AAC、OGG/Opus、FLAC、WAV（各种位深和采样率）、WMA、AC3、AIFF、CAF、WavPack、TTA，以及 MP4、MKV/WebM、FLV、AVI、WMV、MPEG-TS 视频里的声音，B 站客户端缓存的 m4s 也能直接读。人声分离能读哪些格式，以整合包为准，常见的音频格式都可以。

## 限制

- 变声：一次最多 600 秒音频、200 MB 文件。超过容语单次上限（一般 120 秒）的音频，会在安静处切成小段分别变声，再拼回去。同时最多排队 6 段，再多会提示稍后再试。
- 人声分离：一次一个文件，最大 512 MB。容语同一时间只分离一首，同时最多排队 2 首。分离要一些时间，显卡越好越快；单首最长等 30 分钟。
- 只处理本机文件。网络地址、`\\` 开头的共享路径一律拒绝。
- 设置页只能在本机打开的 DSH 里使用，局域网或远程访问 DSH 时这些接口会拒绝请求。

## 常见问题

**变声报「连不上容语」**：容语没开、语音接口没开，或者容语换了端口。容语提示端口变化时，重新复制一次连接串。

**生成的声音没变**：「容语变声（RVC）」的开关没打开，或者连接串没保存成功，这时只转格式。在设置页点「重新检查」看连接状态。

**分离报「当前容语版本不支持人声分离」**：把容语轻量版升级到最新版本。

**分离报「完整版暂时不支持人声分离」**：现在只有容语轻量版能分离。

**分离报「当前整合包没有伴奏分离功能」**：在容语的设置里换成 2026 版 RVC 整合包。

**分离报「显存不够」**：关掉其它占用显卡的程序（比如整合包自己的网页）再试。

**分离的时候实时变声有点卡**：分离和实时变声用的是同一块显卡，同时进行时变声可能会卡。

## 数据存放

全部在 `%USERPROFILE%\.dsh\dsh-rvc\`（设置了 `DSH_HOME` 时在它下面）：

- `settings.json`：设置，包含容语连接串里的 Key，只存在本机。
- `outputs\`：临时生成的 WAV（包括分离出的人声和伴奏），到期自动删除。
- `kept\`：保留模式的默认保存位置。
- `work\`：转换时的临时文件，30 分钟后自动删除。

## 第三方组件

- `bin/ffmpeg.exe`：FFmpeg 9.0.2，LGPL 2.1 或更新版本。只开了音频解码，静态链接，没有 GPL 组件。许可证见 `bin/ffmpeg-LICENSE.txt`，编译配置见 `bin/ffmpeg-BUILD.txt`。想自己从官方源码重新编译替换：下载 [ffmpeg-9.0.2.tar.xz](https://ffmpeg.org/releases/ffmpeg-9.0.2.tar.xz) 解压，在 MSYS2 UCRT64 环境里执行 `SRC=解压目录 bash scripts/build-ffmpeg.sh`，结果会覆盖 `bin/ffmpeg.exe`。
- [silk-wasm](https://github.com/idranme/silk-wasm)：MIT，用来解码 QQ/微信的 SILK 语音。

人声分离不在本插件里运行：分离模型和运行环境都在 RVC 整合包里，由容语轻量版调用。
